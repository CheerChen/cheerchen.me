# AWS Architecture Icons

The SVGs in this folder are copied unmodified from the official AWS Architecture Icons package, release 2026-07-31:
https://aws.amazon.com/architecture/icons/

The icons are owned by Amazon Web Services, Inc. The page says: "We allow customers and partners to use these toolkits and assets to create architecture diagrams." Use them only inside architecture diagrams.

To add an icon, copy its `_48.svg` (service) or `_32.svg` (group) file from the package and register it in `ICONS` in `../archdiagram.py`.
